7Partner console: one-tap verification

New payments arrive in real time with a soft chime and pulse. Staff match the code on the diner's pass and tap Matches. The same dashboard shell as the Tixit organizer console is used, so it's one design system.

Money must be obvious

Every discount is emerald, every line names who funds it, and fees are shown before the pay button, never after.

One thumb, one hand

Main actions live in a bottom dock. Booking and filters open as sheets that close with Back, not as new pages.

One family

Ticket perforation, rose glow, ink scale and press feedback are shared with Events through @tixit/ui.

Calm and accessible

Tabular numbers, AA contrast on both surfaces, 44 px targets and reduced-motion respected.
